# TarHeel CourseMatch

Kenan-Flagler first-year course intel + peer matching prototype for **BUSI 200 Carolina Changemaking Challenge**.

Stack: React · TypeScript · Vite · Tailwind CSS · lucide-react · localStorage

## Run

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

`vite.config.ts` uses `base: './'` for GitHub Pages.

## Data notes

Course facts are drawn from the UNC Catalog, Kenan-Flagler Assured Enrollment / FBA pages, and public syllabi (e.g. ECON 101). Peer tips and match profiles are illustrative. Grading weights marked “typical” vary by section and term.
